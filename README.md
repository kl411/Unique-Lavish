# Unique & Lavish Men's Professional Spa

This is a simple static site for **Unique & Lavish Men's Professional Spa**, ready to upload to GitHub and use with GitHub Pages.

## Files

- `index.html` – Home page
- `styles.css` – Main styles for the site
- `images/logo-round.png` – Placeholder logo image (replace with your real logo)
- `images/banner-home.png` – Placeholder banner image (replace with your real banner)

## How to use with GitHub Pages

1. Create a new repository on GitHub, e.g. `unique-lavish`.
2. Upload all the files in this folder (including the `images` folder) to the repo root.
3. In GitHub, go to **Settings → Pages** and set the source to `Deploy from a branch`, then choose `main` (or `master`) and root.
4. Save. After a minute, your site will be live at the URL GitHub shows you.

## Replacing images

- Export your real **round logo** as `logo-round.png` and put it in the `images` folder (overwrite the placeholder).
- Export your **banner/hero image** as `banner-home.png` and put it in the `images` folder.

The layout and styles will automatically use your updated images.
